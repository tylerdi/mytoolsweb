      状态码只是线索

      429 可以提示控制速率，但 Retry-After 只表示何时可以考虑再次请求，并不保证重试安全。若是有副作用的操作，先确认前一次是否成功，再按服务方支持的幂等机制处理。请求 ID 可以帮助服务方定位单次请求；本站只提取常见头名，其他供应商的命名需要你对照文档。

      缓存线索怎样看

      Age 表示响应在某层缓存中的驻留时间。即使 CF-Cache-Status 不是 HIT，也不能仅凭这一项排除其他缓存层。排查旧内容时，还要对比无查询参数与带临时查询参数的响应、源站状态及缓存规则。

      复制按钮只包含状态、等待时间、请求 ID 和排查步骤，不包含完整响应体；复制前仍请检查请求 ID 是否含敏感业务标识。

      规范依据：RFC 9110 Retry-After、RFC 6585 的 429。详细案例见API 故障排查实战。
