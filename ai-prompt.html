一、Prompt 基础

Prompt（提示词）是你给 AI 的指令。好的 Prompt 能让 AI 输出高质量结果，差的 Prompt 只能得到废话。Prompt Engineering（提示词工程）就是研究如何写出好 Prompt 的学问。

核心理念：AI 是一个极其听话但没有主动思考能力的助手。你给的指令越精确，它的输出越好。

Prompt 的基本结构

一个好的 Prompt 通常包含 4 个部分： 
【角色】你是一个资深的 Python 开发者
【任务】帮我 review 这段代码
【约束】重点关注性能和安全性
【格式】用列表形式给出改进建议

二、6 条黄金法则

1. 明确角色

告诉 AI 它是谁，它会更专业。

❌ 帮我写个邮件
✅ 你是一个专业的商务邮件撰写者，帮我写一封催款邮件，语气要坚定但礼貌

2. 具体任务

模糊的指令 = 模糊的输出。

❌ 写篇文章
✅ 写一篇 800 字的科普文章，主题是"为什么天空是蓝色的"，目标读者是初中生，用通俗易懂的语言

3. 给出示例

Few-shot 学习：给 AI 看几个例子，它就能模仿格式和风格。

按照以下格式写产品描述：
示例：【AirPods Pro】降噪神器，地铁通勤必备，续航 6 小时，¥1899
示例：【Kindle Paperwhite】护眼墨水屏，出差旅行最佳伴侣，续航数周，¥998

现在写：iPhone 16 Pro

4. 限制输出格式

明确告诉 AI 你要什么格式的输出。

用 JSON 格式返回，包含 title、summary、tags 三个字段
用 Markdown 表格对比 A 和 B 的优缺点
用 3 个要点总结，每个要点不超过 20 字

5. 分步思考

复杂任务让 AI 先想再做，输出质量大幅提升。

请按以下步骤思考：
1. 先分析这个商业方案的核心优势
2. 再指出 3 个潜在风险
3. 最后给出改进建议
4. 用表格形式总结

6. 迭代优化

一次写不好没关系，多轮对话逐步完善。

第一轮：写个产品介绍
第二轮：太正式了，改成轻松口语化的风格
第三轮：再加上价格对比和购买建议

三、常用 Prompt 模式

🎯 CREO 框架

Context（背景）：我们公司是一家电商创业公司
Role（角色）：你是一个增长黑客专家
Expectation（期望）：给出 5 个低成本获客方案
Output（格式）：用表格，包含方案名称、预期效果、执行难度、成本

🔗 链式思考（Chain of Thought）

小明有 5 个苹果，给了小红 2 个，又买了 3 个，最后被偷了 1 个。
请一步一步思考，最后小明还有几个苹果？

🎭 角色扮演

你现在是一个面试官，我在面试一个前端开发岗位。
请你问我 5 个由浅入深的技术问题，等我回答后再问下一个。
最后给我一个整体评价。

四、进阶技巧

系统提示词（System Prompt）

在 API 调用中，System Prompt 设定 AI 的全局行为规则。

System: 你是一个专业的技术文档翻译。规则：
1. 技术术语保留英文原文，括号内加中文解释
2. 代码块不翻译
3. 保持原文的 Markdown 格式
4. 语气专业但不生硬

温度控制（Temperature）

控制 AI 的"创造力"。0 = 最精确，1 = 最有创意。

代码生成、数据提取 → temperature: 0
日常对话、文案写作 → temperature: 0.7
创意写作、头脑风暴 → temperature: 1.0

结构化输出

分析以下用户评论的情感，用 JSON 格式返回：
{
  "text": "原评论内容",
  "sentiment": "positive/negative/neutral",
  "confidence": 0.95,
  "keywords": ["关键词1", "关键词2"]
}

评论："这个手机拍照真的很清晰，但电池不太耐用"
