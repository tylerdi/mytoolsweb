# 听雨山寺 · 独立试玩版

2026-11-11。目标：打开网页即可进入一处原创、可漫游的 3D 山寺，短暂休息，无需登录。

## 本版范围

- 原创程序化山寺建筑、山峦、竹林、石径、钟亭、锦鲤池、灯笼与旅人；不下载参考站模型、贴图或声音。
- 点击地面行走，拖动转视角，缩放；键盘方向键 / WASD 移动，碰撞及寻路避开水池、建筑。
- 敲钟、木鱼、喂鱼、静坐 1/3/5 分钟；先走到对应场所再互动，有取消和离开选项。
- 雨、雾、水波、灯光、角色步态；减少动态效果，隐藏页面暂停渲染和音频。
- 用户主动开启后，Web Audio 在本地合成雨、风、钟与木鱼声音。默认静音。
- 分享真实场景截图卡片：支持下载 PNG、复制链接；不支持系统分享时有明确后备入口。
- 本版不发统计事件、不上传输入、只在本地保存语言选择；无虚构在线人数，无广告。

## 验证

- 场景实际加载、点击和键盘移动、建筑/池塘不可穿越、可达交互点。
- 四类活动、计时与结束、静音、雨势、动效、重置视角、分享和下载。
- 桌面与窄屏布局、无 WebGL 时明确提示、控制台错误、构建及寻路单元测试。

## 边界

路径 `/prototypes/rain-temple/`，沿用原型 noindex 策略。先本地评审，不替换现有首页或修改审核中的网站。真实多人房间、账号、付费和在线许愿内容不在本版范围。

## 构建

`npm run build:temple`。Three.js 从锁定的 npm 依赖打包至本目录 `temple.js`，无运行时 CDN 请求。
