隐私政策

两款游戏均不要求注册。以下说明成绩保存、匿名游玩统计和网站托管的边界。

游戏记录与分享

每日航线和潮汐双船的具体路线、完成成绩、步数、提示次数、用时和教学状态以及闯关通关状态、最佳步数与动效开关偏好写入当前浏览器的本地存储，不上传到本站服务器，也不与其他设备同步。分享功能在你点击后调用系统分享面板，或复制游戏链接与不含地图答案的成绩；是否发给别人由你决定。清除本站浏览器数据后，历史成绩无法恢复。

自制关卡

双船关卡编辑器将未完成的设计草稿保存在当前浏览器。点击分享后，礁石、两艘船、两个港口和步数预算会编码进链接；打开链接的人可以读取并试玩这张海图。本站不为自制关卡建立公开图库，也不把草稿上传到服务器。任何拿到分享链接的人都能看到其中的关卡布局，请不要把私人信息写进链接或公开发布包含敏感内容的文字。

匿名游玩统计

游戏向本站自己的统计接口发送固定事件名称和游戏名称，例如打开、开始教学、开始每日挑战、完成、分享，以及次日再次访问。事件 JSON 不包含账号、访客 ID、具体路线、成绩、浏览器标识或来源网址。为避免同一浏览器会话重复计数，浏览器会临时保存当天已发送的事件名；本地还保存上次访问日期，用来判断是否在次日返回。本站只用这些计数判断游戏体验。开启浏览器的 Global Privacy Control 或“请勿追踪”时，游戏不发送统计事件。托管服务仍会按通常方式接收包括来源 IP 在内的网络请求信息。

访问与广告

网页由 Cloudflare Pages 托管。访问页面和统计接口时，托管服务会收到通常的网络请求信息，例如 IP 地址、浏览器标识和访问路径，并可能按其服务规则处理日志。当前游戏页没有第三方访问统计或广告展示脚本；页面包含 AdSense 网站所有权验证标记，但不代表广告已获批准或正在展示。将来若接入广告，会在启用前更新此说明。有关 Google 广告技术，参见Google 的说明。

旧版内容

本站过去提供过 AI 工具、互动功能和 CSV 处理工具。旧页面退出公开入口或返回下线状态，不代表历史数据库记录自动删除。部分旧 API 端点仍可能供历史集成调用；其数据处理方式与当前本地游戏不同。需要咨询历史数据，请通过反馈页面说明问题类型，不要在公开页面提交敏感资料。

联系与更新

涉及隐私的疑问可通过联系页面提出。我们会在功能或数据处理方式发生变化时更新本页，并在页首注明日期。
