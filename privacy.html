隐私政策

区分你选择的文件内容、访问页面时的网络请求，以及本站旧功能可能留存的历史数据。

当前 CSV 工作台

在CSV 体检台选择文件后，浏览器的 JavaScript 读取该文件并在本机解析、预览和生成下载结果。本站没有为这个流程设置文件上传 API；文件内容不提交到本站服务器。选择文件后仍需注意本机浏览器、扩展、剪贴板与下载目录的安全。当前首页不加载广告脚本或站内访问统计脚本。

访问网站时的技术信息

网页由 Cloudflare Pages 托管。你访问页面、CSS、JavaScript 或样例文件时，托管服务会接收网络请求，可能按其运行方式处理 IP 地址、User-Agent、访问路径和安全日志。本站不能通过“不上传 CSV”承诺完全没有网络请求。案例页面可能接入 Google AdSense 的网站验证或广告代码，Google 及其合作伙伴可能使用 Cookie 或类似技术；广告展示取决于网站审核、地区和你的设置。参见Google 广告技术说明。

旧功能的历史数据

本站过去曾提供 AI 聊天、图片、语音、互动功能及访问统计。那些旧页面现已退出公开导航，旧网址下线，但历史内容或数据库记录不会自动消失。它们过去可能将用户主动提交的内容发送到本站 API、第三方服务或数据库。旧版所用的部分 API 端点可能仍供历史集成调用；不要把旧版的数据处理方式与当前本地 CSV 工作台混为一谈。有关历史数据的问题可通过联系页面反馈，不要在公开 Issue 中粘贴个人资料。

选择与更新

生成的 CSV 与 Markdown 报告由浏览器下载到你的设备，你可以自行删除。浏览器本地缓存和网站 Cookie 可通过浏览器设置管理。涉及需要同意的广告地区，站点维护者应在启用广告前配置相应的同意管理方案。本政策随功能变化更新，并在页首注明日期。
