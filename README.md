# 每日航线

`tylerzhang.xyz` 提供两款每天更新的原创海图谜题。首页“每日航线”需要收集航标并规划路线；“潮汐双船”用同一指令移动两艘船，利用礁石和边界让它们分别靠岸。两款游戏都有教学、每日挑战、练习海图和逐步解法回放。成绩保存在浏览器本地，不设账号或排行榜。

## 公开页面

| 路径 | 用途 |
| --- | --- |
| `/` | 游戏、教学、每日挑战与练习 |
| `/twins/` | 潮汐双船、教学、每日挑战与十六张练习海图 |
| `/twins/create/` | 本地关卡编辑、求解验证、试玩与分享 |
| `/guides/` | 五篇与固定练习关对应的精选解题记录 |
| `/rules/`、`/rules/route`、`/rules/twins` | 两款游戏的图示规则与入门路线 |
| `/guides/design-notes` | 真实关卡的预算、分岔与求解边界 |
| `/updates` | 已发布玩法与内容的更新记录 |
| `/replay/` | 逐步解法回放（不索引） |
| `/metrics` | 三个产品的匿名会话阶段、来源与动作汇总（7/14/30 天，不索引） |
| `/about` | 规则、关卡生成与维护说明 |
| `/privacy` | 本地记录、托管请求与历史数据说明 |
| `/contact` | 游戏与隐私反馈 |

每日航线源码位于 `prototypes/daily-route/`，潮汐双船位于 `twins/`。原型只供本地开发，生产 `/prototypes/` 下的 HTML、目录与 Markdown 返回 `410 Gone`；当前游戏依赖的模块与图示仍可加载。`npm run build:game` 将首页的样式、逻辑与图形打包到根目录 `index.html`。旧 CSV 工作台与指南保留在 Git 仓库，但旧公开页面返回 `410 Gone`。历史 API 与数据库记录不会随页面下线自动删除。
精选文章逐项对照具体关卡与求解结果，海图 SVG 由 `npm run build:guide-maps` 生成。自制关卡只把数字化海图写进分享 URL，不上传用户草稿。
精选文章的 `practice-core.mjs` 复用两款游戏的实际规则，四个 `scenarios.mjs` 对照局面与一篇信标机关挑战由测试验证；试走只存在当前页，不写正式闯关进度。参考或对照一经使用，本次面板完成不作为自主完成上报，重置后可重新独立尝试。反馈页只生成与复制本地草稿，不假装已经提交。
两款游戏的“航海闯关”提供 12 / 16 张固定海图：通关后直接下一关，也可在关卡地图中任选；最佳步数和提示次数只在本机保存。航线 v3 继承前八关 v2 进度，后四关机关地图重新计通关；旧版本记录不删除；每日成绩与双船进度保持原样。`assets/voyage.mjs` / `.css` 共享闯关进度、海面动效、移动与通关反馈；动效可关闭，并遵循系统“减少动态效果”设置。最后一关返回关卡地图，不循环加载同一关。
航行动效在独立浮层上绘制船只、双侧尾流、水波与航标粒子，连续操作衔接当前视觉位置；重置、换图和关闭动效会清理浮层并恢复真实船只。历史图标 URL `/resource/easyclaw.png` 兼容返回当前航线 logo，页面与生成模板均使用当前品牌图标；图标使用重新验证缓存策略。

## 本地开发

```bash
npm ci
npm run build:game
npm run build:guide-maps
npm test
HOST=127.0.0.1 PORT=8788 python3 local_server.py
```

打开 `http://127.0.0.1:8788/`。若只修改游戏源码，先运行 `npm run build:game` 再提交根目录 `index.html`。构建还会生成本地可直接打开的 `prototypes/daily-route/daily-route.html`，该文件不会提交。

## 产品边界

- 同一天的每日关卡对所有访客相同，按上海时间 00:00 更新；每日航线闯关 v3 分简单（1–4）、标准（5–8）、困难（9–12）三档；固定关卡由求解器验证最短路线、预算内全部可行航线与误导岔路，前八关逐步收紧预算；后四关保留更多开放水域并加入航闸、潮桥状态，不以解法数量严格下降代替难度设计，潮汐双船的练习按最短解步数递进。双船新每日题从 2026-11-06 起采用八套地形与求解器质量筛选；旧日期题保持不变。
- 生成器确保存在合法路线；不保证唯一解。提示每局最多 3 次。
- 记录只在当前浏览器本地保存。清除站点数据后无法恢复。
- 当前不加载广告展示脚本。三产品统一匿名统计由同属 Tyler 的 jimao.tylerzhang.xyz 汇总接口提供，记录固定产品、事件、有限来源和动作计数，不发送访客 ID、完整网址、路线或成绩。`/metrics` 与 `https://jimao.tylerzhang.xyz/metrics/` 展示同一汇总；次数不是独立人数。旧 `/api/stats` 口径保留。统计可在各站隐私页关闭，详见 `assets/insights/README.md`。AdSense 网站验证标记不代表审核通过。

## 发布

推送 `main` 后由 Cloudflare Pages 自动部署。上线后检查两款游戏、匿名统计、关于/隐私/反馈、`sitemap.xml`、`ads.txt` 和旧 CSV 页面 `410`。游戏上线供试玩与收集反馈，不等于已准备好重新申请 AdSense 审核。

## 听雨山寺独立试玩

`/prototypes/rain-temple/` 是一处原创的单人 3D 庭院，提供石径寻路、敲钟、木鱼、看鱼、1/3/5 分钟静坐、合掌致意、可拖动念珠、雨景和本地合成音效。合掌在当前位置完成，念珠支持鼠标/触摸拖动、惯性、按钮及键盘逐颗拨动，次数仅保留在当前页面。点击地面行走，拖动画面环顾，滚轮或双指缩放；方向键 / WASD 也能行走。左上方可切换中文 / English / 日本語 / 한국어；首次按浏览器语言选择，之后只在本地保存语言偏好。分享链接携带语言。右上方可设置声音、雨势和减少动态效果。隐藏页面暂停场景更新、音频与静坐计时。

运行 `npm run build:temple` 后启动本地服务器访问该路径。Three.js 随本地脚本打包，无运行时 CDN；建筑、植被、角色和声音均由本站代码生成，无参考站素材。无登录、多人在线或广告；正式站已接入可关闭的匿名汇总（来源、进入、互动、静坐完成、分享）。明信片在本地生成并保存；本地地址只供本机预览。产品范围见 `prototypes/rain-temple/PLAN.md`。本地原型保留 noindex 标记；生产的原型页面返回 410，不替换每日航线首页。

## 山寺的独立正式站

听雨山寺使用 `temple.tylerzhang.xyz` 和独立 Cloudflare Pages 项目 `rain-temple-tyler`。源码在 `codex/rain-temple-launch` 分支；每日航线的 `main` 与 `mytoolsweb` 项目继续负责原站。`npm run build:temple:site` 只生成山寺的静态正式包，不发布旧 API。首次采用控制台 Direct Upload；推送源码本身不会更新山寺。完整发布步骤见 `prototypes/rain-temple/DEPLOYMENT.md`。
