# 每日航线

`tylerzhang.xyz` 的首页是一款每天更新的航线谜题。玩家从码头出发，收集三个航标、绕过礁石，遵守洋流方向并在步数预算内抵达灯塔。首次访问提供 8 步互动教学；另有 12 张固定练习海图。每日成绩保存在浏览器本地，不设账号或排行榜。

## 公开页面

| 路径 | 用途 |
| --- | --- |
| `/` | 游戏、教学、每日挑战与练习 |
| `/about` | 规则、关卡生成与维护说明 |
| `/privacy` | 本地记录、托管请求与历史数据说明 |
| `/contact` | 游戏与隐私反馈 |

源代码位于 `prototypes/daily-route/`。该目录保留不可索引的开发原型；`npm run build:game` 将样式、逻辑与图形打包到根目录 `index.html`。旧 CSV 工作台与指南保留在 Git 仓库，但旧公开页面返回 `410 Gone`，不再进入导航或站点地图。历史 API 与数据库记录不会随页面下线自动删除。

## 本地开发

```bash
npm ci
npm run build:game
npm test
HOST=127.0.0.1 PORT=8788 python3 local_server.py
```

打开 `http://127.0.0.1:8788/`。若只修改游戏源码，先运行 `npm run build:game` 再提交根目录 `index.html`。构建还会生成本地可直接打开的 `prototypes/daily-route/daily-route.html`，该文件不会提交。

## 产品边界

- 同一天的每日关卡对所有访客相同，按上海时间 00:00 更新；练习编号不表示难度等级。
- 生成器确保存在合法路线；不保证唯一解。提示每局最多 3 次。
- 记录只在当前浏览器本地保存。清除站点数据后无法恢复。
- 当前不加载广告展示或访问统计脚本。AdSense 网站验证标记不代表审核通过，也不保证未来审核结果。

## 发布

推送 `main` 后由 Cloudflare Pages 自动部署。上线后检查首页玩法、关于/隐私/反馈、`sitemap.xml`、`ads.txt` 和旧 CSV 页面 `410`。游戏上线供试玩与收集反馈，不等于已准备好重新申请 AdSense 审核。
