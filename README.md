# 每日航线

`tylerzhang.xyz` 提供两款每天更新的原创海图谜题。首页“每日航线”需要收集航标并规划路线；“潮汐双船”用同一指令移动两艘船，利用礁石和边界让它们分别靠岸。两款游戏都有教学、每日挑战和练习海图。成绩保存在浏览器本地，不设账号或排行榜。

## 公开页面

| 路径 | 用途 |
| --- | --- |
| `/` | 游戏、教学、每日挑战与练习 |
| `/twins/` | 潮汐双船、教学、每日挑战与八张练习海图 |
| `/metrics.html` | 匿名游玩事件的 7/14/30 天汇总（不索引） |
| `/about` | 规则、关卡生成与维护说明 |
| `/privacy` | 本地记录、托管请求与历史数据说明 |
| `/contact` | 游戏与隐私反馈 |

每日航线源码位于 `prototypes/daily-route/`，潮汐双船位于 `twins/`。前者的不可索引原型仍供开发使用；`npm run build:game` 将首页的样式、逻辑与图形打包到根目录 `index.html`。旧 CSV 工作台与指南保留在 Git 仓库，但旧公开页面返回 `410 Gone`。历史 API 与数据库记录不会随页面下线自动删除。

## 本地开发

```bash
npm ci
npm run build:game
npm test
HOST=127.0.0.1 PORT=8788 python3 local_server.py
```

打开 `http://127.0.0.1:8788/`。若只修改游戏源码，先运行 `npm run build:game` 再提交根目录 `index.html`。构建还会生成本地可直接打开的 `prototypes/daily-route/daily-route.html`，该文件不会提交。

## 产品边界

- 同一天的每日关卡对所有访客相同，按上海时间 00:00 更新；每日航线的练习编号不表示难度等级，潮汐双船的练习按最短解步数递进。
- 生成器确保存在合法路线；不保证唯一解。提示每局最多 3 次。
- 记录只在当前浏览器本地保存。清除站点数据后无法恢复。
- 当前不加载广告展示或第三方统计脚本。两款游戏只向本站 `/api/stats` 发送固定匿名事件名，不发送访客 ID、路线或成绩。`/metrics.html` 读取汇总数字；它不代表独立访客数。AdSense 网站验证标记不代表审核通过。

## 发布

推送 `main` 后由 Cloudflare Pages 自动部署。上线后检查两款游戏、匿名统计、关于/隐私/反馈、`sitemap.xml`、`ads.txt` 和旧 CSV 页面 `410`。游戏上线供试玩与收集反馈，不等于已准备好重新申请 AdSense 审核。
