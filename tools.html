UTF-8 Base64 / Base64URL

编码的是 UTF-8 字节。Base64URL 使用 -、_ 并在输出时省略填充；解码仅接受 UTF-8 文本，二进制文件不在此工具的范围内。



  
URL 参数编解码
处理单个查询参数的值，而不是整个网址。若要构造完整网址，请用 URL 和 URLSearchParams。


  
时间戳与 ISO 时间
明确选择秒或毫秒；反向转换只接受包含 Z 或时区偏移的 ISO 时间，避免“本地时间还是 UTC”的歧义。


  
JavaScript 正则测试
在独立 Worker 中检查匹配，运行超过 600 毫秒会停止。最多列出 100 个匹配；生产数据仍应在实际运行环境测试。


  
SHA-256 文本摘要
使用浏览器 Web Crypto 计算 UTF-8 文本摘要。摘要有助于比较内容是否一致，不能代替密码散列或数字签名。


  
UUID v4
使用浏览器的 crypto.randomUUID()。适合生成测试请求标识；业务幂等仍需要服务端保存和核对键的使用记录。
