Tyler / API Lab

面向正在接入模型 API 的中文开发者，集中处理输出契约、请求失败、流式响应与用量成本。

这里提供什么

JSON 检查与Schema 校验用于确认输出边界；SSE 检查和响应头诊断用于保留请求证据；故障记录器把脱敏事实和下一步整理为 Markdown。成本预算和用量分析分别处理事前估算和事后复算。

内容如何维护

站点由 Tyler 维护，代码公开可查。指南优先给出可复现的输入、输出、失败边界和所依据的规范。涉及第三方费率或行为时注明核对日期并链接官方资料；供应商仍可能修改服务，生产决策应以最新文档和账单为准。发现错误可通过反馈渠道告知。

内容范围

本站曾有娱乐、聚合新闻和日更图片等实验页面；与当前开发者工作台无关的入口已经下线。现在公开维护的内容聚焦可验证的浏览器工具、模型 API 成本与排错案例。数据库中先前由用户提交的内容不会因为页面下线而自动删除；有关数据的问题可通过联系页面反馈。

工具页可帮助排查与估算，但不代替服务端校验、权限控制或正式报价。处理真实业务数据时，请先阅读隐私政策。
