关于本站

Tyler 工作台

这是 Tyler 维护的独立工具站，面向正在接入模型 API、处理结构化输出和搭建 Agent 工作流的中文开发者。

这里提供什么

首页的JSON 输出检查器使用浏览器原生解析器；JSON Schema 校验检查字段契约，SSE 检查辨认事件边界，响应头诊断提取故障线索。成本预算页估算单一场景，用量日志分析复算规范化 CSV；工具调用实验用固定场景说明失败处理。其他浏览器开发工具与排错指南围绕这些任务展开。

内容如何维护

指南优先使用可复现的输入、输出和失败边界。涉及第三方 API 的价格或行为时，会注明核对日期并链接官方资料；即使如此，供应商仍可能随时修改服务，生产决策应以其最新文档和账单为准。发现错误时欢迎通过反馈渠道告知。

内容范围

本站曾有娱乐、聚合新闻和日更图片等实验页面；与当前开发者工作台无关的入口已经下线。现在公开维护的内容聚焦可验证的浏览器工具、模型 API 成本与排错案例。数据库中先前由用户提交的内容不会因为页面下线而自动删除；有关数据的问题可通过联系页面反馈。

工具页可帮助排查与估算，但不代替服务端校验、权限控制或正式报价。处理真实业务数据时，请先阅读隐私政策。
