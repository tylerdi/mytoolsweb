什么时候需要做结构对比

一次模型或 SDK 升级后，HTTP 请求可能仍返回 200，但字段的类型、名称或完成原因已经改变。仅检查 JSON 语法会漏掉这类回归。先保存一个已通过业务验收的基准响应，再把新响应与它对比，能把排查范围缩小到具体字段路径。

怎样解读结果

/usage/input_tokens 是字段路径，斜线与波浪号按 JSON Pointer 规则转义。缺失字段意味着基准中有、当前响应没有；新增字段则相反。值变化只说明两个标量不相同，不代表哪一个值业务上正确。

数组按位置比较。若项目顺序变化，可能显示多处值变化；请根据业务主键人工核对。此工具不做语义判断，也不会上传输入。摘要不含字段值，但字段名本身也可能敏感，分享前请检查。
