回程留门：二十步收齐三个航标

第二个航标离灯塔很近，但靠近终点不代表能立刻靠岸。先留出经过第三个航标的通道，才不会被自己已经走过的格子截断回程。

关卡数据：第 8 关 · 7×7 海图 · 预算 20 步 · 最短 20 步 · 预算内 5 条可行航线

先看码头旁的封口

码头在第四行第一列，右边和下方都是礁石，因此要先向上。连续向上三步到第一行第一列的洋流，再沿顶边向右走，取得第一行第三列的航标。第一行第四列仍要求向右，路线继续到第五列，再向下进入第二行，随后向右拿到第二行第七列的航标。

靠近灯塔时不要急着结束

此时只收集了两个航标。向下进入第三行第七列后，洋流要求向左，沿第六列下行到第四行，再向左经过第五列，进入第四行第四列的向下洋流。顺箭头到第五行第四列，就能取得最后一枚航标。这个转折把去程留在第四行、回程放在第五行，避免重复经过已经走过的格子。

把下方通道留作回程

收齐后向右走三步，到第五行第七列，再向上一格到灯塔。这条示例路线正好 20 步，没有绕路余量。如果先占用第五行的回程通道，后面即使看到灯塔，也可能因为不允许重复经过而接不上终点。

上 → 上 → 上 → 右 → 右 → 右 → 右 → 下 → 右 → 右 → 下 → 左 → 下 → 左 → 左 → 下 → 右 → 右 → 右 → 上

为什么这一关属于标准档

求解器在实际 20 步预算内穷举出 5 条合法航线，因此这条示例并不是唯一答案。与前段关卡相比，本关不再留绕路余量，必须把航标顺序、洋流出口和最后一段回程连起来考虑。可以先独立尝试，卡住时再用逐步回放核对自己的转折。
