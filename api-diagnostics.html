选择状态和操作类型，获得下一步排查顺序。这里不需要输入 API 密钥、提示词或完整响应。

只在服务方实际返回时填写。支持秒数或 GMT 格式 HTTP 日期。

排查建议

    如何使用这份判断

    状态码是线索，不是最终诊断。先看响应体里的服务方错误代码、请求标识和时间，再对照对应接口文档。本站的判断规则在浏览器里运行，不发送表单内容；勾选“有副作用”只改变重试建议。

    为什么副作用会改变答案

    只读查询通常可以在限制次数和总时限的前提下重试。创建订单、发送通知和扣费操作则可能在客户端超时前已经成功；再次提交前必须核实结果，并确认服务方或业务系统的幂等机制。Retry-After 只告诉你何时可以考虑再次请求，不保证重试安全或一定成功。

    不要在公开工单中分享密钥、个人数据或完整用户提示词。实际生产环境还需设置并发上限、错误预算和告警；本页不替代供应商文档。

    规范依据：RFC 6585 的 429 定义、RFC 9110 的 Retry-After。
