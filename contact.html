联系与反馈

发现错误或文档与实际不符，请告诉我们能复现问题的最小步骤。

提交公开问题

请在项目 GitHub Issues中描述：文件编码、分隔符、表头和 2 至 3 行经过脱敏的样例、预期结果与实际结果。需要 GitHub 账号。我们会优先处理能够在当前版本中重现的问题。

GitHub Issues 是公开页面。不要上传原始客户 CSV、邮箱、电话号码、身份证号、账户资料、密钥或私人对话；先用自己构造的同结构样例复现。

隐私相关问题

有关旧功能的历史数据或当前文件处理方式，请在 Issue 中只说明问题类型，不要附敏感内容。我们会在不公开个人数据的前提下提供进一步沟通方式。当前工作台的文件只在浏览器本地读取，本站不提供用户文件云端存储。
